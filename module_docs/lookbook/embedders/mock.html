lookbook.embedders.mock

Deterministic mock embedder for tests and end-to-end orchestration.

MockEmbedder returns a vector seeded by image_id, so the same image always yields the same vector and similar `image_id`s yield similar vectors (a tiny bit). It does not require any ML dependency.

class lookbook.embedders.mock.MockEmbedder(space_id: str = 'mock', cost_tier: int = 0, dim: int = 64, seed: int = 0, backend: str = 'lookbook:mock')[source]

Deterministic, dependency-free embedder for tests.

The vector is derived from a SHA1 of image_id (mixed with seed), expanded to dim dimensions, and L2-normalized.
