lookbook._paths

Default paths for lookbook persistent state, via config2py.

All path resolution funnels through here so that swapping app names or storage roots is a one-place change.

lookbook._paths.app_folder(kind: Literal['data', 'config', 'cache', 'state'] = 'data', *, ensure_exists: bool = True) → str[source]

Return the user-app folder for lookbook of the requested kind.

>>> p = app_folder("data")
>>> p.endswith("lookbook")
True
